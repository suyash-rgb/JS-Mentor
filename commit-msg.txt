Changes Made

Backend ML Module
extract_training_data.py
Created a standalone ETL module that queries SQLAlchemy models (Student, StudentProgress, ExerciseEvaluation, QuizEvaluation).
Automatically filters qualified students who have completed Learning Paths 1 and 2.
Aggregates per-student interaction metrics (time_spent_seconds, avg_exercise_attempts, avg_exercise_execution_time_ms, exercise_is_correct_ratio, quiz_score, quiz_attempt_number).
Derives empirical ground-truth risk_level labels (HIGH, MEDIUM, LOW).

train.py
Updated train() to dynamically extract live database records via extract_real_training_data(db).
Merges real student DataFrames with baseline synthetic data (synthetic_training_data.csv) using pd.concat.
Implemented atomic candidate file saving (risk_model_candidate.joblib) followed by atomic rename to risk_model.joblib to prevent server file-lock issues during live inference.
Calls MLService.reload_model() to clear cached in-memory instances.

ml_service.py
Added reload_model() classmethod to reset _model = None so the FastAPI backend dynamically reloads fresh model weights from disk on the next prediction call.

student_service.py
Added _check_and_trigger_retraining(db) event-driven trigger in log_exercise and log_quiz.
Checks overall evaluation volume milestones (e.g. every 50 new submissions) and asynchronously dispatches background retraining threads.
