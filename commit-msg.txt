fix: broken call for /practice-hub/all

Root Cause of 0 Questions on /practice-hub/all

In PracticeQuestions.js, fetchData was executing Promise.all calling GET /api/v1/practice/progress.
That endpoint (/progress) did not exist on the backend and threw a 404 error, causing the entire Promise.all to reject and jump to catch() before setQuestions() could ever run.
Fix: Replaced the broken call with GET /api/v1/practice/stats and decoupled get('/api/v1/practice/questions') so the full question list loads independently of user stats.

Different API Endpoints for /practice-hub vs /practice-hub/all

app/routers/practice.py
Added a new endpoint: GET /api/v1/practice/questions/featured?limit=10 which returns only the top limit (default 10) questions for the Practice Hub landing page.
Added "total_questions": len(load_practice_data()) to the response of GET /api/v1/practice/stats.
