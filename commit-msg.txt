fix: 500 for /api/v1/trainer/cohorts

Root Cause
In GET /api/v1/trainer/cohorts (list_cohorts in trainer.py), the endpoint was passing SQLAlchemy Student ORM model instances directly into CohortResponse(students=c.students). 
Because Pydantic v2 requires explicit ORM attribute conversion for nested list schemas (StudentMini), it threw a validation error (18 validation errors for CohortResponse students.0 Input should be a valid dictionary or instance of StudentMini).

Solution Applied
1.Explicit Serialization (app/routers/trainer.py:L178): Converted the SQLAlchemy student objects into structured dictionaries [{"id": s.id, "name": s.name} for s in c.students] when building CohortResponse.
2.Pydantic Schema Upgrade (app/schemas/cohort.py:L26-L45): Added from_attributes = True to StudentMini, CohortResponse, and GroupClassResponse for Pydantic v2 ORM compatibility.
