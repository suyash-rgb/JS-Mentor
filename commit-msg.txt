feat: Anti-Cheat Proctoring Enhancements

1. Dynamic Base Viewport Calibration
Instead of relying on hardcoded viewport differentials, the engine now captures a baseWidthDiff and baseHeightDiff when the editor mounts.

Sidebars and split-screen detections are now calculated as deltas from this base calibration, meaning it works flawlessly across different OS DPI scalings, window states, and resolutions.
Implemented in: 
FinalExamPage.js
, 
ExerciseCompiler.js
, 
PracticeCompiler.js

2. Multi-Screen & Hibernation Tracking
Hibernation Detection: We now listen to the pagehide event to catch when the session is backgrounded or pushed into hibernation by modern browsers.
Multi-Screen Check: We check window.screen.isExtended to flag the usage of multiple monitors during exams.
Implemented in: 
FinalExamPage.js
 and 
ExerciseCompiler.js

3. Active DevTools Detection (Debugger Loop)
A detached DevTools console cannot trigger a resize event. We introduced a 1-second interval loop executing a debugger; statement.
If DevTools is open, execution pauses. We measure the pause time using performance.now(). If it exceeds 100ms, a security violation is triggered.
Environment Toggle: As requested, this logic is strictly scoped to production or when REACT_APP_ENABLE_DEVTOOLS_BLOCK=true is set in the 
.env
 file to ensure local development remains frictionless.
Implemented in: 
FinalExamPage.js
 and 
ExerciseCompiler.js

4. Input Hardening (Typing Speed Heuristics)
We analyze onDidChangeModelContent events in Monaco.
To prevent "simulated pastes" (e.g., using Autohotkey or keyboard macros), we measure the time delta between consecutive typing events.
If text is injected consistently under 25ms (which is faster than human capability), the engine triggers a simulated undo via editor.trigger('keyboard', 'undo', null) and issues a warning.
Implemented in: 
ExerciseCompiler.js
 and 
PracticeCompiler.js
